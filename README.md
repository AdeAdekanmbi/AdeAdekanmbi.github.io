# Adeoluwa Samuel Adekanmbi — Personal Portfolio

Personal portfolio website showcasing my research, projects, resume, and CV.

## Built With
- HTML5
- [Tailwind CSS](https://tailwindcss.com/)
- [GSAP](https://greensock.com/gsap/) + ScrollTrigger
- [Font Awesome](https://fontawesome.com/)

## Sections
- **Home** — Introduction with typewriter effect and aurora background
- **About** — Bio and stat counters
- **Resume / CV** — Downloadable documents with preview
- **Research** — Flip cards for MIT and Howard University research projects
- **Projects** — Hackathon and coursework projects
- **Contact** — LinkedIn, GitHub, and email
